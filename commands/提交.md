请为当前改动生成提交信息并提交。补充说明：$ARGUMENTS

步骤：

1. `git status` + `git diff` 看清改了什么；`git log --oneline -10` 看历史提交的信息风格
2. 按项目**已有风格**写提交信息，不要自创格式
3. 只提交本次相关的文件，不要 `git add -A` 一把梭
4. 若当前在默认分支（main / master），**先提示我**，不要直接提交
5. 提交后把 `git status` 结果贴出来确认

如果发现改动里混杂了不相关的修改，先告诉我，由我决定怎么拆。
