请帮我管理 Claude Code 的模型选配（简体中文输出）。脚本：`python3 ~/.claude/claude-model.py`。

**为什么用这个脚本**：本机 `ANTHROPIC_BASE_URL` 指向第三方网关（DeepSeek），TUI 里的 `/model` 与
`claude --model` 候选来自 Anthropic 官方清单，**不含 DeepSeek 真实模型名**，所以只能靠这个脚本改
`~/.claude/settings.json` 的 `env` 段。请在一开始就说明这一点。

## 按参数分派

- **无参数**：执行 `python3 ~/.claude/claude-model.py`，把「当前主模型 / 小快模型 / 自动压缩窗口 /
  base_url / 密钥（已脱敏）/ 内置候选 + 缓存清单」用紧凑列表复述给用户。密钥一律只显示脱敏形式。
- **`--list`**：执行 `python3 ~/.claude/claude-model.py --list`，列出候选模型（在线优先，失败自动回退
  缓存 / 内置清单）；标注哪些支持 1M 上下文与当前正在用的模型。
- **`--refresh`**：执行 `python3 ~/.claude/claude-model.py --refresh`，尝试拉取在线目录并写缓存。
  若提示「无法刷新在线模型目录 / 网络不可达」，如实转述并说明会继续用内置清单，不要重试多次。
- **`--set <模型>` / `--set-small <模型>`**：**必须先 dry-run，再等用户确认**：
  1. 第一步只执行 `python3 ~/.claude/claude-model.py --set <模型> --dry-run`（`--set-small` 同理），
     把 JSON diff 原样展示给用户（哪个字段、从什么变成什么，含备份文件名）。
  2. 明确询问用户是否确认执行，**在用户回复确认之前，绝对不要执行不带 `--dry-run` 的命令**。
  3. 用户确认后，执行不带 `--dry-run` 的同一命令并复述结果：新值、备份路径。
  4. 结尾必须提示：**「重启 claude 会话后生效」**（当前会话仍跑旧模型）。
  5. 若用户想只换小快模型或保留小快模型/窗口，提示可用 `--keep-small`、`--keep-window`。
- **`--help`**：执行并展示帮助文本。

## 规则

- 模型名带 `[1m]` 后缀表示 1M 上下文，脚本会同步把 `CLAUDE_CODE_AUTO_COMPACT_WINDOW` 设为 `786432`；
  不带 `[1m]` 时按 128K 窗口的 3/4 规则设为 `98304`。
- 切换默认会同步小快模型 `ANTHROPIC_SMALL_FAST_MODEL`；只想改主模型时加 `--keep-small`。
- 任何情况下都不要手工编辑 `~/.claude/settings.json`，也不要改动 `~/.claude/statusline.py`、
  `theme.py`、`claude-usage.py` 与 `~/.claude/commands/` 下的其他命令文件。
- 脚本自身负责备份（`settings.json.bak-model-<时间戳>`）与原子写校验，无需人工干预。
- 输出保持紧凑，不要长篇大论；命令出错（非法模型名、路径不存在）时如实转述报错与退出码。
